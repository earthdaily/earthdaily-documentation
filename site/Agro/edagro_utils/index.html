    edagro_utils🔗

    Version: 2.3.0

    edagro_utils is a Python package providing utilities for analytics bulk extraction from the EarthDaily Agro API. It offers a comprehensive set of tools for authentication, data extraction, processing, and analysis of agricultural satellite data.

    Installation🔗

    pip install edagro_utils-2.3.0-py3-none-any.whl

    Package Structure🔗

    Module Description
    Core Base classes, authentication, API utilities, geometry tools, and logging
    Extractors Service-level extractors for vegetation time series, field level maps, coverage, weather, and more
    Processors Processor-based analytics: emergence, harvest, greenness, change index, scores, and more
    Services Workflow orchestration, S3 cloud storage, user and entity management
    Reporting HTML report generation for extraction runs

    Quick Start🔗

    from edagro_utils import EDAuthenticator, setup_environment

# Setup environment and authenticate
config = setup_environment(env="prod")
auth = EDAuthenticator(env="prod")
token = auth.get_token()

    edagro_utils — Utilities for analytics bulk extraction from EDAgro API.

    core — Base classes, auth, API utils, geometry, logging, URLs extractors — Service-level extractors (coverage, disease, FLM, VTS, weather, ...) processors — Processor-based extractors (emergence, harvest, greenness, ...) services — Workflow manager, user/entity management, S3, layer service analysis — Data analysis, raster processing, predictive coverage

    ChangeIndexExtractor 🔗

    Extracts change detection analytics between two NDVI images.

    Detects significant changes in field conditions using multi-temporal satellite analysis. Compares vegetation index values between two dates to identify areas of improvement or degradation.

    Note: This class does not inherit from BaseExtractor and has its own initialization pattern.

    Documentation: https://earthdaily.github.io/earthdaily-documentation/Agro/Library/Change_Index/ Notebook: EDAgro_coverage_Function_Dev.ipynb

    Args (init): bearer_token (str): Authentication token env (str): Environment ('prod' or 'preprod')

    Entity fields

    id, geometry (required); image_id_1, image_id_2 (two images to compare)

    Output columns

    entity_id, change_index, change_category, + change detection metrics

    InSeasonMonitoringExtractor 🔗

    Bases: BaseExtractor

    Extracts in-season crop monitoring analytics for agricultural entities.

    Combines satellite and weather data for real-time crop performance monitoring. Supports multi-resolution data sources (LR and MR) and configurable season windows.

    Documentation: https://earthdaily.github.io/earthdaily-documentation/Agro/Api_reference/ Notebook: EDAgro_InSeasonMonitoring_Processor_Function_Dev.ipynb

    Args (setup_inseason_monitoring_parameters): season_duration (int): Season length in days. Default: 120 season_start_day (int): Season start day of month. Default: 1 season_start_month (int): Season start month. Default: 4 year (str): Target year. Default: '2025' data_source (list): Data sources (['LR', 'MR']). Default: ['LR', 'MR']

    Entity fields (via column_mapping): id, geometry (required); crop, sowing_date (optional)

    Output columns

    entity_id, + in-season monitoring metrics and alerts

    validate_wkt(geometry: Union[str, BaseGeometry, None], verbose: bool = False) -> str

    Validate and normalize geometry to a WKT string.

    Accepts WKT strings or shapely geometry objects. Shapely objects (e.g., from a GeoDataFrame's geometry column) are automatically converted to WKT.

    Parameters:

    Name Type Description Default
    geometry Union[str, BaseGeometry, None]

    WKT geometry string or shapely geometry object

    		 required
    verbose bool

    Whether to log progress messages

    		 False

    Returns:

    Name Type Description
    str str

    Validated WKT string

    Raises:

    Type Description
    ValueError

    If geometry is None, empty, or invalid
    TypeError

    If geometry is not a string or shapely geometry

    Examples:

    >>> validate_wkt("POINT(0 0)", verbose=True)
>>> validate_wkt("POLYGON((0 0, 1 0, 1 1, 0 1, 0 0))", verbose=True)
>>> from shapely.geometry import Point
>>> validate_wkt(Point(0, 0))  # returns "POINT (0 0)"
