# Dynamic Compute

An on-demand geospatial compute engine.

Dynamic-Compute is a map computation engine. It enables users to
dynamically generate maps from a composable set of Python operations.
Together, these properties enable data scientists in the building of
complex GIS applications.

The Dynamic Compute API can be found as Python package
`earthdaily-earthone-dynamic-compute`, and
can be imported as
`earthdaily.earthone.dynamic_compute`.
