# API

## Clients

- **Catalog** - `earthdaily.earthone.catalog` - Create, manage, search, and visualize raster products and imagery
- **Compute** - `earthdaily.earthone.compute` - Parallelize computations with scalable compute
- **Vector** - `earthdaily.earthone.vector` - Catalog for vector data
- [Dynamic Compute](api/dynamic-compute.md) - `earthdaily.earthone.dynamic_compute` - On-demand geospatial compute engine

## Authentication and Configuration

- **Auth** - `earthdaily.earthone.auth` - See the [Authentication](authentication.md) guide
- **Config** - `earthdaily.earthone.config` - See the [Configuration](configuration.md) guide

## Geo

- **GeoContext** - `earthdaily.earthone.geo` - See the [GeoContext Guide](guides/geocontext.md)

## Utilities

- **Utils** - `earthdaily.earthone.utils` - Display, Properties, and other utility functions
