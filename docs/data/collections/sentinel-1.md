# Sentinel-1

C-band synthetic aperture radar (SAR) imagery from ESA's Sentinel-1 constellation, enabling all-weather, day-and-night Earth observation.

## Available Collections

| Collection Name | Collection Id | Processing Level | Time Range |
|-----------------|---------------|------------------|------------|
| Sentinel-1 GRD | `sentinel-1-grd` | Ground Range Detected | Starting Oct 2014 |
| Sentinel-1 RTC | `sentinel-1-rtc` | Radiometrically Terrain Corrected | Starting Oct 2014 |

## Key Characteristics

- **Spatial resolution**: 10–40m depending on acquisition mode
- **Revisit time**: 6–12 days
- **Polarization**: VV, VH, HH, HV
- **Wavelength**: C-band (5.405 GHz)

## Notes

- **GRD** products are the standard ground range detected format. Source: AWS Open Data — [Sentinel-1](https://registry.opendata.aws/sentinel-1/)
- **RTC** products have been radiometrically terrain-corrected to reduce topographic distortion. Source: Microsoft Planetary Computer — [Sentinel-1 RTC](https://planetarycomputer.microsoft.com/dataset/sentinel-1-rtc)
